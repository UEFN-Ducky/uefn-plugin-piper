# Pipe

Real neural voices that run 100% on your PC — no API key, offline, free forever. Powered by Piper. Pick a voice per ducky (or as the default); drop your own .onnx voice models in to add more.

Desktop plugin for [UEFN-Ducky](https://github.com/UEFN-Ducky/UEFN-Ducky) (`piper`).
Install or update from **Settings → Store** in the app — do not install from a zip by hand.

## Build

```bash
py scripts/build_zip.py
```

Writes `deploy/piper-1.0.11.ducky-plugin.zip` (scripts/ and deploy/ are not packed).
